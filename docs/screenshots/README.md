# Capturas de Pepino+

Las capturas de Bambi (en rojo) se quitaron con el rediseño. Para hacer capturas nuevas desde la tele, con ADB:

```
adb connect IP_DE_LA_TELE:5555
adb exec-out screencap -p > 01-perfiles.png
```

Nombres sugeridos: 01-perfiles, 02-inicio, 03-ficha, 04-fuentes, 05-reproductor, 06-audio-subtitulos,
07-buscar, 08-ajustes, 09-editar-perfil.
